🪟 Defenestrator Configuration

Configure prioritized windows and URL patterns to organize your tabs

Tagged Windows (Priority Order)

Windows are checked in order. The first matching window's rules will be used. The last window is the default—all unmatched tabs go there. Use the up/down arrows to reorder windows and change priority.

Set Default ClassifiedWindow

Choose which window should be the default. Tabs that don't match any rules will go here.
